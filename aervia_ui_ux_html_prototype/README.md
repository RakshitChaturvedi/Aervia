# Aervia UI/UX HTML prototype

Open `overview.html` in a browser. Use the left navigation to move between the pages.

## Pages
- `overview.html` — primary College Gate dashboard
- `events.html` — event catalogue
- `event-detail.html` — event evidence and recovery
- `alerts.html` — warning inbox
- `exposure.html` — integrated PM excess ledger
- `activity.html` — activity association and observation form
- `interventions.html` — intervention register and verification
- `reports.html` — College-Gate Environmental Report preview
- `quality.html` — data quality and sensor readiness

## Notes
- This is a static HTML/CSS/JavaScript prototype with illustrative, hard-coded content based on the current `ft1_final_v2` capture and product specification.
- Charts and some page interactions are mockups. Forms, warning acknowledgment, intervention records, and report generation are not connected to the backend.
- The chart is illustrative and should not be treated as an exact export of the sensor time series.
- It intentionally labels the capture as historical, warns about provisional thresholds, and avoids claiming source attribution or population exposure.
- No external libraries or network requests are required. Keep all files in the same directory.
